- (decision) Source of record for this run: docs/project-brief.md UI-relevant sections (idea, platform features, judge experience, scope). The 2026-11-05 decision freeze is treated as binding where it updates that brief.
- (decision) Product is a morning front page: newspaper layout, headline size reflecting importance, a short briefing, today's calendar, and tasks. Email, iOS, push, real-time collaboration, and auto-printing are out.
- (decision) Surfaces: Android and Desktop in the contest pair; web newspaper, light editing, and a server admin panel are committed with the Ktor milestone. PDF, audio edition, and the Android home-screen widget have no screens in this spine.
- (decision) First launch with no config shows a sample edition from bundled fixtures. No account and no AI key required. With no key, an extractive fallback still fills the page.
- (decision) One edition document per local calendar date. A user edit is part of the document and survives regeneration. Last write wins. Single user. The edition screen does not reveal whether the repository is local or remote.
- (decision) Desktop owns the typewriter-style editor. Web views the newspaper and does light editing. Android has customization settings, a morning local notification, and the on-device calendar. Desktop has a system tray. Server access is LAN plus a shared token.
- (decision) Calendar sources in the first milestone: Android on-device calendar, an ICS URL, and CalDAV. Tasks in the first milestone are a local list. News is RSS and Atom only.
- (decision) Web admin configures feed URLs, ICS and CalDAV calendars, generation time and timezone, AI provider and key, and the shared token. Standalone Android and Desktop keep local settings when no server is running.
- (assumption) Masthead word is Matutine. The brief still lists the final name as open; Daily Newspaper is the working title.
- (assumption) Importance is shown as three ranks — lead (at most one), secondary, and note — mapped to three type sizes. The ranking formula is not defined here.
- (assumption) The page reads as newsprint: warm paper, near-black ink, a single dark-red masthead rule, serif headlines, hairline column rules, no cards and no shadow on the edition. Settings and admin use Compose Material 3 chrome. No dark theme.
- (assumption) Typewriter edits the briefing and the story text in one monospaced column. Calendar events and tasks stay structured fields. Web light edit changes those same text fields in place. Android edition text is read-only.
- (assumption) Android customization is: notification time (default 07:00 local), feed URLs, calendar source, optional Gemini key, optional server URL and token. Incomplete tasks stay on the local list and show on later editions.
- (assumption) Named protagonists are labels for roles in the sources: Sam for the contest judge, O for the author.
- (assumption) English copy only. WCAG 2.2 AA for text on the paper. The edition date is the generator's timezone: device-local when standalone, the admin timezone when the server generates.
